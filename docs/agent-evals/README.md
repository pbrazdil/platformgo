# Agent evaluation reports

Store reviewed reports required by `AGENT_EVALS.md` here. Test fixtures and expected outcomes live under `testdata/agent-evals/`; this directory contains dated comparison reports only.

Filename:

```text
YYYY-MM-DD-short-change-name.md
```

Each report records the exact model (`gpt-5.6-sol`), profile, reasoning effort, reasoning context, standard/pro mode, verbosity, prompt/config revision, task success, required evidence, rule violations, approvals, tokens, cache metrics, latency, tool calls, retries, and human decision.
